# Zainab Yusuf – Portfolio

React (Create React App) + Tailwind CSS v3.

```bash
npm install
npm start        # http://localhost:3000
npm run build    # production build
```

## Where to edit
- `src/data/projects.js` – demo projects (image, video, details). Add a project by adding one object.
- `src/data/liveWork.js` – live products with links.
- `src/data/experience.js` – work history and skills.
- `src/data/socials.js` – email, GitHub, LinkedIn.
- `tailwind.config.js` – colour palette and fonts.
